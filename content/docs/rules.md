## What rules do

Rules run automatically over new mail as it syncs, **before**
notifications fire — so a filed newsletter never buzzes your phone.

Each rule pairs one condition with one action. A rule matches on:

- **Sender contains…**, or
- **Subject contains…**

and when it matches, it can:

- Move the message to a folder
- Mark it as read
- Flag it
- Delete it (moves to Trash)

Matching is case-insensitive. A rule can apply to one account or to
all of them.

Rules are included on the free tier.

## Creating a rule

1. Open **Settings → Rules**.
2. Tap **Add Rule** (or **New rule** on Android).
3. Choose the field (sender or subject), enter the text to match,
   pick the action, and choose which account it applies to.

## How rules are applied

- Rules apply to **new mail only** — creating a rule doesn't sweep
  your existing inbox.
- Rules run oldest-first, and the **first matching rule wins** for
  any given message.
- Toggle a rule off in the Rules list to pause it without deleting
  it; swipe to delete it entirely.

Deletions performed by a rule go to the account's Trash folder, so
a misfiring rule never destroys mail permanently.
