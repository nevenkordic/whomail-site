## Free and Pro

WhoMail's free tier is a complete mail app, not a demo:

| | Free | Pro |
|---|---|---|
| Email accounts | One | Unlimited |
| Unified inbox, folders, move | ✓ | ✓ |
| Full search, local and server | ✓ | ✓ |
| Compose, signatures, attachments | ✓ | ✓ |
| Calendar, invitations, contacts | ✓ | ✓ |
| Rules, snooze, send later | ✓ | ✓ |
| Instant push notifications | — | ✓ |

Privacy is never gated: on-device processing and the no-cloud-AI
guarantee apply to every user, free or paid.

## Pricing

- **Monthly:** A$4.99 per month
- **Annual:** A$39.99 per year, with a **7-day free trial**

Subscriptions are billed through the App Store and shared across your
devices with the same Apple ID.

## Subscribing, restoring, cancelling

- Subscribe from **Settings → WhoMail Pro**, or when the app offers it
  (for example when adding a second account).
- On a new device, use **Restore Purchases** in the same screen.
- Cancel any time in the App Store's subscription settings; Pro
  features remain active until the end of the paid period.
