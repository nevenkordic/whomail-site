## Free and Pro

WhoMail's free tier is a complete mail app, not a demo. Instant
Push is **not** gated — closed-app alerts are included for
everyone.

| | Free | Pro |
|---|---|---|
| Email accounts | One | Unlimited |
| Unified inbox, folders, move | ✓ | ✓ |
| Full search, local and server | ✓ | ✓ |
| Compose, signatures, attachments | ✓ | ✓ |
| Calendar and contacts | ✓ | ✓ |
| Mail rules | ✓ | ✓ |
| Instant push notifications | ✓ | ✓ |
| Insights summary + heatmap | ✓ | ✓ |
| Ranked people list & profiles | Top 2 people | Full |
| Snooze | — | ✓ |
| Send Later | — | ✓ |

Privacy is never gated: on-device processing and the no-cloud-AI
guarantee apply to every user, free or paid.

## Pricing

- **Monthly:** A$4.99 per month
- **Annual:** A$39.99 per year, with a **7-day free trial**
- **Lifetime:** A$200 one-time (not a subscription)

Subscriptions are billed through the App Store or Google Play and
follow that store's account. Lifetime is a one-time unlock.

## Subscribing, restoring, cancelling

- Subscribe from **Settings → WhoMail Pro**, or when the app
  offers it (adding a second account, snooze, Send Later, or the
  rest of the Insights list).
- On a new device, use **Restore Purchases** in the same screen.
- Cancel a subscription in the App Store or Play Store
  subscription settings. Pro features remain active until the end
  of the paid period.
- Lifetime does not renew and does not expire.
